# Examples

- [cv-format.md](cv-format.md): the resume format the AI writes and the tools read. It is also a complete sample resume (a fictional HR business partner) that you can use to try the flow without your own resume: copy it to `cv.md` in the main folder.

To see every resume design with your own resume, ask the AI to "show me the resume designs" (it runs `npm run resume -- preview`).
